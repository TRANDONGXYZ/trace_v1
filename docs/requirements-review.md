## Remaining interaction limitations

Undo history is in memory, has no fixed count cap, and ends on reload; only the current diagram is autosaved. Large edit histories may use substantial browser memory. Gesture tests cover mouse-wheel, Ctrl-wheel and the browser's Ctrl-marked pinch event; a physical Windows trackpad/browser matrix has not been certified. Enter/Ctrl+Enter in Description is the documented resolution of natural multiline editing versus the previous single-line Enter submission. These are explicit implementation limits/choices, not new approved roadmap items.

Successful import intentionally clears prior history and replaces rather than merges. Files are unencrypted and limited to 25 MiB; browser storage can be smaller. Native save-location selection is browser-dependent; fallback confirms download initiation only. Synchronous validation and rendering may pause large diagrams; measured browser commit/render/Close for 1,000 nodes was approximately 2.8 seconds on the test machine, not a guarantee. Mobile emulation does not certify every physical phone/file picker. No file transfer or inference occurs during backup operations.

The taller-card follow-up standardizes all seven types at 96 units high with a 32-unit vertical gap. Older coordinates reflow for compatibility without changing event text/dates/relationships or causing a load-time save/history entry. Current-layout saves preserve positions after deletion/reload. The previous pan sign inversion is reversed in both axes; tests model all four natural-trackpad directions and synchronized rulers. Physical finger-to-wheel mapping still depends on device/OS scrolling settings.

Reaction-time details quote original fields and state that no interval reason is inferred. They do not attempt to decide whether descriptions explain a delay. Recorded event dates are not decision timestamps or proof of causality/severity. Repeated traversals are memoized for UI interactions, but many roots with large shared downstream graphs can still cost time/memory; no reaction-analysis latency target is established.

Consequence Chain Analysis resolves the requested structural-depth, distinct-total and selected-duration distinction, with deterministic branch selection and original event timelines. It shares phase totals and processes acyclic Consequence tails once; only a selected timeline is reconstructed. Unit tests cover a 10,000-node chain and a branching graph with exponentially many possible paths; browser tests cover 150 segments and mobile/resized panels. These are functional scale checks, not a latency guarantee. Extremely many roots/deep chains can still produce large lists/DOMs; no virtualization or historical-phase selector is added. Cycle results remain explicitly unavailable under A-09, and invalid selected dates have no duration.

## Verification of this update

Achievement Path Analysis adds a read-only complete ancestor graph and original Action details. Layering avoids overlaps between node boxes; it does not optimize every edge crossing or prove time order. Cyclic components remain original nodes, and reachability highlights may include cyclic relationships before the destination. Functional scale coverage includes 10,000-node cyclic data, an acyclic graph with exponentially many possible paths and a 40-Action converging browser graph. These are correctness/usability checks, not guaranteed latency or exhaustive large-graph performance certification. Many achievements sharing large ancestor graphs still require per-root counting, and rendering is synchronous. No virtualization, expanded graph view or historical-phase navigation is added.

Passed locally on 14 November 2026: **167 unit/security tests**, **102 browser tests**, **5 production-bundle tests with mocked AI**, production build and Wrangler dry run. New coverage verifies upstream Action counts, complete ancestor/edge preservation, direct/indirect classification, all-route highlighting, phase filtering, deterministic non-overlapping layers, cycle termination, original descriptions, four-way detail selection and read-only viewport/save/history isolation. Light/Dark, minimum-width, wide converging graphs and mobile views pass; existing chain, reaction, phase, backup, whiteboard and AI regressions also pass. Earlier backup performance samples remain in [Backup schema](backup-schema.md); they are observations, not achievement-analysis latency guarantees. Browser emulation is not a physical-device matrix or formal accessibility certification. Build succeeds with the existing non-blocking bundle-size warning. AI logic and Cloudflare configuration remain unchanged; no real inference or deployment was performed.
